4.2  Document Verification

Loan officers must manually verify borrower-submitted tax returns against IRS records using the legacy Tax Transcript Request Form (Form 4506-T), submitted via fax to the Compliance mailbox within 3 business days of application receipt.

If a submitted transcript cannot be matched to IRS records, the loan officer must escalate to a Tier 2 underwriter for manual review before proceeding.

4.2  Document Verification

Loan officers must verify borrower-submitted tax returns against IRS records using the automated Tax Transcript API integration, which returns validated transcript data within 1 business day of application receipt. Manual Form 4506-T submission is only required if automated verification fails or returns an error.

If a submitted transcript cannot be matched to IRS records, the loan officer must escalate to a Tier 2 underwriter for manual review before proceeding.
